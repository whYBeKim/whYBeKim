### About me
👋 Hi, I'm **YoungBeom Kim**, a Ph.D. student at the [Crypto & Security Engineering Lab (CSE)](https://sites.google.com/kookmin.ac.kr/cselab/), Kookmin University.

I work on **post-quantum cryptography (PQC) implementation and hardware security**, from constrained MCUs to RISC-V and FPGA/ASIC datapaths.

📂 For my publications and projects, please visit my homepage → **[ybgraphy.com](https://www.ybgraphy.com/)**

### Research Interests
- Efficient PQC implementation on constrained devices
- HW/SW co-design and RISC-V ISE for PQC
- Fault-tolerant arithmetic and side-channel analysis
- Constant-time verification
- KpqC standardization

🛠️ C · Assembly · Verilog · Python &nbsp;|&nbsp; ☕ Coffee brewing & cupping
